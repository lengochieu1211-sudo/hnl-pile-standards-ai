# HNL Pile Standards AI v1.9.3

## Icon Pro & Windows Identity

- Tối ưu icon HNL cho 16–256 px trên Windows.
- Giữ nguyên logo HNL, chỉ giảm khoảng trống và tăng độ rõ ở kích thước nhỏ.
- ICO đa kích thước dùng cho Setup EXE, Portable EXE, Desktop Shortcut, Start Menu và File Explorer.
- PNG 32/48/64/192/512 dùng cho Web/PWA/Electron.
- Electron đặt AppUserModelID cố định để Windows gom đúng taskbar icon.
- Không thay đổi RAG, AI, Formula, Reader Pro hay Model Manager.
