PR #3 · P0 Windows SPT Absolute Path Repair

ROOT CAUSE
- scripts/spt-pdf-decision-golden.mjs used new URL(import.meta.url).pathname with path.resolve().
- On Windows GitHub Actions this produced a duplicated drive path such as D:\\D:\\a\\...

FIX
- Use existing scripts/cross-platform-paths.mjs helper moduleDir(import.meta.url), which is based on fileURLToPath().
- Use resolveCliOutputPath() for optional output path.
- Add an in-runner Windows absolute-path regression probe using path.win32.
- Keep locked 574 regression test count unchanged.

UNCHANGED
- Calculation Engine
- SPT normative policy
- src/search.js
- Golden baseline identity 1.25.7
- App version 1.26.0
