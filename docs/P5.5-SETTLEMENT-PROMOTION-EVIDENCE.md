## Source audit

The project PDF `TCVN 10304:2025` was rechecked visually at pages 62-65 before promotion. CT (41)-(45) define the equivalent-block settlement components. CT (46) appears at 7.4.4.5 and defines an alternative interaction coefficient δ for the stated irregular pile-layout condition, replacing CT (37) when that condition is intentionally selected. P5.5 therefore keeps CT (37) as the default group-interaction formula and exposes CT (46) only through an explicit irregular-layout/CT46 request with pile diameter `d` present.
