# P5.8 Piled Raft Method / Applicability Gate

Source: TCVN 10304:2025, 7.4.5.1-7.4.5.7, standard pages 65-66.

No closed-form piled-raft capacity formula is invented. The gate verifies applicability and required interactions; final design requires numerical/spatial deformation and internal-force assessment. Undeclared consolidation is surfaced as an explicit warning for backward compatibility; an explicitly unfinished-consolidation site is prohibited per 7.4.5.3. Production numeric Excel export is blocked.
